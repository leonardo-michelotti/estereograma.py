Como funciona · antes da fórmula

A profundidade nasce de um deslocamento.

O estereograma não desenha um objeto. Ele organiza repetições para que cada olho encontre o mesmo pixel em posições ligeiramente diferentes.

Agora a fórmula

Uma regra geométrica, linha por linha.

A fórmula modela a distância entre os olhos e reduz a separação à medida que o ponto se aproxima. Depois, o motor descarta superfícies ocultas e preserva o vínculo visível mais próximo.

O código real

A intuição vira Python.

Este é o núcleo usado pelo V2 para calcular o par de cada pixel. Antes de criar o vínculo, ele confirma a visibilidade e resolve conflitos em favor da superfície mais próxima.

Testar no EstúdioAbrir o módulo completo ↗
z = z_row[x]
sep = int(round(
    (1.0 - mu * z) * E
    / (2.0 - mu * z)
))

left = x - sep // 2
right = left + sep

if visible[x] and 0 <= left and right < width:
    if current_constraint_is_nearer:
        look_left[right] = left
        look_right[left] = right
